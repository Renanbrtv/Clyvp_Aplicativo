## Limites da verificação

Não houve compra Google Play real ou de licença de teste, acesso a projeto RevenueCat do proprietário, chamada OpenAI real, entrega Resend real, notificação em celular, migração de banco do usuário, deploy ou revisão da loja. Faça esses testes com suas credenciais e uma build Android antes do lançamento.

O verificador de produção rejeita intencionalmente esta configuração de exemplo: falta URL HTTPS real, dados do responsável, retenção preenchida e chave pública Android do RevenueCat. Não remova essas verificações para gerar uma versão com serviços indisponíveis.

## Reproduzir testes no backend

Use somente banco separado, com `test` no nome, e `NODE_ENV=development`. Configure-o no `.env`, aplique migrações e seeds fictícios, inicie a API e rode em outro terminal:

```sh
npm run test:api
npm run test:release
npm run test:cly
npm run test:providers
```

No frontend, execute `npm run typecheck` e `node scripts/test-reminders.cjs`. Os testes escrevem e apagam registros de teste. Nunca use o banco de produção.
